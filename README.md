# API Key Manager

一个安全的桌面应用程序，用于管理和存储所有 API 密钥。

## 功能特性

- **AES-256-GCM 加密**：所有 API 密钥使用主密码加密存储
- **分类管理**：支持自定义分类标签
- **多环境支持**：开发/测试/生产环境隔离
- **搜索过滤**：快速查找 API 密钥
- **一键复制**：快速复制密钥到剪贴板
- **导入/导出**：JSON 格式数据备份
- **API 连通性测试**：验证 API 密钥是否有效
- **余量查询**：查看 API 使用额度/余额
- **测试历史**：记录每次测试结果

```bash

```

## 使用说明

### 首次使用

1. 启动应用后，设置主密码
2. 主密码用于加密所有 API 密钥，请牢记

### 添加 API Key

1. 点击右上角"+ 新建"按钮
2. 填写名称、API Key、选择分类和环境
3. 可选：配置测试端点和余量查询端点
4. 点击保存

### 测试 API 连通性

在创建/编辑 API Key 时，配置测试端点：
- **测试端点**：API 的测试 URL，使用 `{API_KEY}` 作为密钥占位符
- **请求方法**：GET 或 POST
- **自定义请求头**：JSON 格式，如 `{"Authorization": "Bearer {API_KEY}"}`

配置后，列表中会显示测试按钮（绿色勾号图标）。

### 查询 API 余量

配置余量查询端点：
- **余量查询端点**：查询余额/使用量的 URL
- **余量 JSON 路径**：指定返回 JSON 中余量的位置，如 `data.balance` 或 `usage[0].remaining`

配置后，列表中会显示查询按钮（紫色图表图标）。

## 数据安全

- 使用 AES-256-GCM 加密算法
- PBKDF2 密钥派生（100,000 次迭代）
- 数据存储在用户数据目录：`%APPDATA%/api-key-manager/`
- 导出的 JSON 文件包含明文密钥，请妥善保管
